# QR Code Generator

A simple web application that generates QR codes from text or URLs. Users can enter data, generate a QR code instantly, preview it on the page, and download the QR image.

## Features

- Enter text or URL
- Generate QR code instantly
- Preview QR code on the page
- Download generated QR code
- Validates invalid URLs and shows an alert
- Simple and responsive UI

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

```bash
QR Code Generator/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Open the project folder.
2. Open `index.html` in a browser.
3. Type text or a valid URL in the input box.
4. Click the "Generate QR Code" button.
5. Click "Download QR Code" to save the image.

## Usage

- Valid example: `https://example.com`
- Invalid example: `google`

If the input is invalid, the app displays an alert: `Enter a valid URL`.
